# Active Projects

Place or mount current project packages here for local Production Execution.

Project subdirectories are ignored by Git. The public PRD-Creator repository must not become the storage location for live project/client data.

Multiple active projects are allowed. Select the project named by the user or clearly established by the current conversation; ask when project focus is ambiguous.

Project lifecycle, retention, validation commands, and the project-data boundary live in `../README.md`.
