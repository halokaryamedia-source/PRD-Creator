The original Voice Production Kit v1.0.0 `Voice Production.docx` was re-read, rendered, and visually inspected during Flow 6. Its SHA-256 is recorded below. The source binary is not duplicated into this repository through the current GitHub write connector; instead, its demonstrated contract is codified in `DOCX-FORMAT.md` and `builder/build_docx.py`. It demonstrates:

- cover hierarchy;
- gameplay-section grouping;
- Main Story / Radio type labels;
- title and Estimated Duration hierarchy;
- shaded performance-script panels;
- square-bracket directions;
- selective emphasis, pauses, and line-break readability.

It does **not** define how many voice moments another project needs or what that project should say.

The v1.0.0 package also paired this DOCX with `Gameplay.html` V1.2. That legacy HTML is intentionally not duplicated into the active kit because Flow 6 now uses each project's accepted `work/content.md` / PRD revision as upstream factual authority. The legacy pair remains recoverable from the original archived kit/source if historical comparison is needed.
