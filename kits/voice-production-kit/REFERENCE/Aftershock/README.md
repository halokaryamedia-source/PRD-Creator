# Aftershock Voice Reference

The original Voice Production Kit v1.0.0 used a paired Aftershock gameplay document and `Voice Production.docx` as its approved production reference.

For **Flow 5**, use the reference only to understand demonstrated voice-function patterns:

- Main Story carries mission/story context, transitions, major state changes, completion/reward/farewell;
- Radio Communication carries short in-play warnings, progress, urgency, encouragement, reminders, and recovery;
- voice entries are grouped by gameplay section;
- section counts vary naturally; no fixed number of Main Story/Radio entries is required.

Do not derive project facts from Aftershock.

The binary DOCX/paired gameplay reference is intentionally deferred to **Flow 6**, where formatting and performance-script quality become active concerns. Current projects must always extract voice requirements from their own accepted PRD revision.
