# Minimal Navigation

Use this as the shortest resume path.

## Resume First

1. `../../AGENTS.md` — working rules and authority.
2. `../../CONTEXT.md` — stable facts and terminology.
3. `next-action.md` — single active task/state and next step.

Do not ask the user to reconstruct previous work before checking these owners.

## Then, Only If Needed

- `decision-log.md` — when the reason behind a durable decision matters.
- `../foundation/README.md` — when product/workflow policy matters.
- `implementation-map.md` — when the current owner/location is unclear.
- affected kit/project source — when actual implementation/content behavior must be inspected.

## Stop Rule

If the answer is not in the boot context, open the smallest relevant owner next. Do not broad-scan saved projects, all references, generated output, or old chats by default.
