# Task Board

Updated: 2026-08-12

Use this page for **future/non-active work only**. It never overrides `../next-action.md`.

## Future work

There is no standing parity or hardening backlog.

Future work begins only from:

- a real new project through the existing production Flow;
- an explicit user-requested product/system change;
- Maintenance for a concrete observed defect.

Do not create work merely to mirror BuildIT, increase ceremony, or make the repository look more complete.

## Closed work

Completed implementation phases, remediation checklists, CI run IDs, and one-off proof cycles are not duplicated here. Their durable meaning belongs in decisions/reviews; detailed chronology remains in Git history.
