# Workspace Map

## Main Areas

- `../../AGENTS.md` — repository-wide rules and authority.
- `../../CONTEXT.md` — stable product context.
- `../foundation/` — durable workflow/product policy.
- `next-action.md` — one active continuation point.
- `decision-log.md` — durable decisions and reasons.
- `implementation-map.md` — current owner/location map.
- `operations/task-board.md` — future/non-active work.
- `../../workspace/` — per-project working data and outputs.

## Fast Rule

```text
new session
→ AGENTS
→ CONTEXT
→ next-action
→ smallest relevant foundation/kit/source
```

Do not treat generated output, old reference content, or saved project packages as the default source of current project state.
