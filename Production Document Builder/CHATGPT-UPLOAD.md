# ChatGPT Upload Package

This archive is prepared for direct upload through ChatGPT Skills.

## Archive Layout

`SKILL.md` is located at the root of the ZIP. Supporting references, templates,
schemas, scripts, tests, examples, and the locked Golden Sample are stored in
subdirectories beside it.

## Upload

1. Open ChatGPT.
2. Open **Skills**.
3. Select **Create** or **New skill**.
4. Select **Upload from your computer**.
5. Upload `production-document-builder-chatgpt-skill-v0.2.0.zip`.
6. Review the scan result and install the skill.
