# Acceptance Criteria

The installable Skill package is accepted when:

- SKILL.md and all eight references are present;
- all schema and semantic tests pass;
- all five Document Profiles and Specialized variants render;
- non-Frozen content is rejected;
- exact Golden Sample regression passes;
- the locked Golden SHA-256 matches;
- an end-to-end Frozen workspace produces HTML, ZIP, Render Report, and HTML Audit;
- final output contains sidebar, View Mode, Terms Used, and Golden Template CSS;
- Critical and Major findings are zero before delivery.
